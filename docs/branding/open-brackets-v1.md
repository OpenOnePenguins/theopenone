# The Open One — Open Brackets

## Direction

A friendly cloud mascot made from two soft, inward-facing code brackets. The two white eyes retain the character of One's visual reference; the open center and bracket-shaped body express source code and openness.

- **Palette:** near-black and white; transparent background.
- **Shape:** two broad lobed halves, one eye per half, with an open center.
- **Use:** standalone project logo concept. Small-size and inverted toolbar treatments should be derived after visual selection.
- **Reference:** [One](https://getone.one/), with its installed application icon inspected as a visual reference. This asset is a newly generated concept.
