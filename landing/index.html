A few things to know

Good questions.

A little clarity before you dive in.

What does open source mean for me?+

You can inspect how The Open One works, change the native Swift code to suit your workflow, and build your own version. Start with the source checkout and the build instructions above. Your coding agents still use their existing accounts and billing.

Is The Open One another coding agent?+

Your coding agents do the coding. The Open One gives their conversations, questions, and finished work a shared home on your Mac. It can start local Claude Code and Codex sessions using your existing CLI setup.

How is it related to One?+

The Open One is an independent, open-source native macOS recreation, inspired by One. It is built with original SwiftUI and AppKit code and does not use One’s private source or backend. It does not yet offer full feature parity.

Can I keep using my terminal?+

Yes. The Open One can observe recent local Claude Code and Codex conversations. For direct control of a live terminal session, connect it through the optional Herdr integration. You can also resume eligible idle conversations or start new sessions in The Open One.

Where do my conversations go?+

The Open One keeps its app data on your Mac. Managed requests use the agent CLI you installed and its existing authentication. Optional AI recipient suggestions send your draft and limited candidate context through Claude Code; you choose the recipient before sending. Dictation uses Apple’s Speech framework.

Can I check in from my phone?+

Yes. The mobile Inbox lets you read conversations, answer agent questions, and continue supported sessions from your phone. Your Mac stays awake with The Open One running. Open Remote access on your Mac, click Connect phone, and scan the QR on your phone while both devices are on the same Wi-Fi network. The open-source mobile client is also included in the repository.

What do I need to run it?+

macOS 13 or later, Apple’s Swift Command Line Tools to build the app, and an installed, signed-in Claude Code or Codex CLI for managed agents. Python 3 is required by the build tools and agent bridge. Your agents keep using their existing subscriptions or billing.
